# 共通介面偏好

本文件記錄使用者在 Game Companion 的介面與操作偏好，隨 repo 一起版本管理，供家裡與公司的開發環境共同遵循。新增功能或調整既有介面前，先讀本文件；既有功能在實際修改時逐步對齊，不因新增規範而批次改版。

以下是預設方向。使用者當次明確要求優先；若資料量、手機操作或效能需要例外，應說明原因與影響，不自行把例外擴成所有模組的慣例。

2026-11-19 使用者確認納入下列 01～25 項，並於後續補充調整：切換功能重設搜尋與篩選，收集相關清單預設尚未蒐集（含 Grounded）；表格依預期資料量決定是否使用內部捲動；長章節可依區域與行進段落再分類；搜尋搭配的篩選可用下拉，逐項收集狀態優先直接勾選。此補充取代先前「切換功能保留條件」「所有一般清單禁止內部捲動」「同章不能再分段顯示」及一概優先按鈕篩選的解讀。未完成篩選下勾完立即移除的規則維持。以下為預期規範，不代表所有模組已完成套用。

## 路線圖採漸進式收合清單

- 目前選定的章節／區域／行進段落內，未完成的步驟與子項預設全部展開，能直接連續閱讀與勾選，不必逐項打開。完整展開的範圍是目前閱讀單元，不要求整章所有區域同時堆在一頁。
- 完成後才收合成標題、完成狀態與必要摘要；整段或整章完成後可再精簡。
- 路線圖內的收集細項完成後，保留緊湊方塊、已勾選框與項目名稱，收起位置、走法等細節；可直接取消勾選並恢復全文，不能只留下「此地已完成」而無法辨認完成哪些項目。此規則適用於路線內嵌項目；獨立查漏清單的未完成篩選仍勾完立即移除，路線明確選擇只看未完成時依其篩選範圍處理。
- 已完成內容可臨時展開回看，取消完成後恢復全文；展開、定位與閱讀都不改寫完成進度。
- 在「只看未完成／未取得」篩選下，勾選完成或取得後立即移出結果，不暫留到重新篩選；可切換全部／已完成查看或取消。一般未套用此篩選的路線圖仍按完成收合規則顯示摘要。
- 勾選與收合時維持閱讀位置及焦點，不強制跳到下一步；重要警告仍須在需要時可見。
- 詳細互動與驗收依 [漸進式收斂 Roadmap UX](PROGRESSIVE_ROADMAP_UX.md)。該文件的第一階段調查要求限於 Roadmap 改版工作。

## 清單完整顯示，路線圖依章節與行進段落分類

- 一般資料清單一次顯示目前條件下的全部結果，不做分頁，也不要求按「載入更多」才能繼續看。
- 路線圖先依遊玩階段分章；章內內容仍長時，依區域、行進段落或劇情流程再分類，可切換閱讀單元，以平衡頁長與資訊消化量。
- Talos II 是適用例子：單章內容過長，依區域再劃分片段供玩家切換瀏覽，符合本規範；不能僅因存在章內片段切換而判為不符。
- 目前選定閱讀單元內符合條件的內容一次呈現，不以固定筆數分頁或「載入更多」截斷。分類須有行進與內容語意，避免任意切碎短段落或要求逐步開啟未完成攻略。
- 使用章節導覽、錨點目錄、搜尋與篩選協助定位。其他章節可自由切換、提前閱讀，不能以尚未完成前章為由鎖住。
- 「完整顯示」與漸進式收合並行：未完成內容完整展開，已完成內容保留可回看的摘要。
- 此偏好適用於同一份內容的閱讀，不要求將不同遊戲或不同功能合併成單頁，仍保留獨立頁面模組。

## 下拉選單依操作頻率取捨

- **搜尋與清單篩選：** 一次搜尋搭配幾個篩選下拉是合理做法，少量選項也不必一律改成按鈕。依畫面空間、名稱長度與操作便利選擇下拉、按鈕或分段按鈕，不因使用下拉本身判定不符。
- **道具列內反覆修改收集狀態：** 優先直接勾選／取消；需要多個直接選項時採清楚的按鈕，不讓每件物品都先開下拉再選狀態。上百件收集品不得因此多出上百次開選單的操作。
- 章節、區域或角色等導航選擇，可使用下拉或可搜尋選單，不與逐項收集狀態混為一談。
- 單選或多選語意須清楚，選取狀態不只靠顏色區分，並支援鍵盤操作與輔助科技辨識；按鈕不應擠壓閱讀區。
- 僅提供對當前任務有用的篩選，避免增加不必要的種類與組合。

## 操作與進度（01～07）

01. **進度以勾選／取消為主。** 完成狀態採簡單二態，避免增加略過、不確定、已錯過等操作。熟練度、實際數量等具有數值語意的資料仍使用適合的輸入方式；資料查證狀態與玩家完成狀態分開。
02. **原處即可勾選。** 路線圖中的收集物與獎盃可直接操作，不要求切到另一份清單才能記錄。
03. **同一項目共用紀錄。** 攻略、收集清單、獎盃頁及地圖出現同一項目時，反映同一份狀態，不重複打勾或累計。
04. **操作即存檔。** 不另設一般儲存按鈕；保存成功後更新同遊戲的其他分頁。保存失敗須明確提示，不能顯示為已保存；本機存檔不等於自動雲端同步。
05. **步驟、取得與跳盃分開。** 步驟完成、物品取得、實際 PSN 跳盃各自確認，達到追蹤條件不能自動代勾獎盃。
06. **保留可辨識的獨立步驟。** 不為減少勾選數，把多個需要分別確認的操作合併成含糊的一組。
07. **提供撤銷。** 一般進度操作及批次勾選提供清楚的撤銷入口；撤銷只回復該次操作，不覆蓋其後其他操作或其他分頁的新變更。匯入、初始化等仍沿用原有備份與確認保護。

## 閱讀與導航（08～15）

08. **可自由提前閱讀。** 切章、定位或瀏覽後續內容不代填進度，不以完成度鎖住攻略。
09. **能快速返回遊玩進度。** 提供返回遊玩進度／繼續下一步入口，從實際紀錄找待處理內容；閱讀位置與完成進度分開，不能因提前閱讀就跳過未完成項。
10. **維持閱讀位置與焦點。** 更新、收合或篩除項目時避免畫面跳動，不強制捲到下一項。未完成篩選下仍須立即移除已完成項，移除後將焦點留在鄰近可操作項或結果區，不為保留焦點而暫留該列。
11. **風險在操作前提示。** 不可逆、容易錯過、備份需求與前置條件放在相關步驟旁，重要警告不因完成收合而隱藏。
12. **攻略寫具體動作。** 交代地點、準備、操作及成功判定，避免只列「完成支線」等概括目標；缺乏證據時明示缺口。
13. **閱讀與查證細節分開。** 遊玩頁保留操作及必要警告；來源比對、驗證與補救紀錄集中於來源與查證頁，需立即採取的補救動作仍在相關步驟提醒。
14. **清單緊湊，詳情按需展開。** 武器、角色等優先一項一列，先顯示名稱、狀態與關鍵數值；成本、用途與來源可展開。路線圖目前閱讀單元內的未完成步驟仍全文展開，不套用隱藏攻略的詳情模式。
15. **依預期資料量決定捲動方式。** 資料不多的表格與清單隨整頁捲動，不另設內部捲動區，方便快速瀏覽。預期資料很多的表格可設內部捲動區，避免頁面過長；捲動時須維持表頭欄位可見，方便對照。依完整資料量與實際畫面判斷，不設任意筆數門檻；搜尋後暫時少量結果不表示該大型表格必須更換布局。地圖等需要縮放拖曳的互動區另依操作需求處理。

## 搜尋、查漏與資料呈現（16～22）

16. **收集清單預設尚未蒐集。** 收集與查漏清單進入或切換功能時，預設顯示尚未蒐集／未取得／未完成內容，保留全部與已完成入口；Grounded 也適用。使用者在目前功能內可自行調整條件，切換功能後重設。未完成篩選下勾完立即移除，不等下次篩選。純資料參考頁不因本條強加收集狀態。
17. **搜尋涵蓋原文與別名。** 搜尋包含繁中、已知英文／日文、別名及適用編號，任務代號支援如 M1／M01 的等價寫法，不只搜尋畫面主名稱。
18. **進度數字可直接協助查漏。** 分類／等級進度卡可點擊篩選，獎盃條件可連到對應缺項；互動入口與目前選取狀態須清楚可辨。
19. **相關內容直接互跳。** 配裝名稱連到圖鑑、獎盃連到取得路線、地圖連到收集列，避免要求重新搜尋。
20. **繁體中文優先，原文放次要位置對照。** 介面、攻略、地名、角色、道具、技能及獎盃以可理解的繁中為主要閱讀內容；英文／日文放在中文後方或下一行，以較小字級作辨識與搜尋對照。優先採有證據的遊戲內官方中文；沒有官方中文對照時，允許使用一致的社群譯名或本站參考翻譯，不能因此讓玩家只能閱讀英文。參考翻譯不冒充官方用詞，具體來源分級、格式與例外依下節。
21. **本體、DLC、特典及白金範圍分清楚。** 圖鑑可以涵蓋全部內容，但白金條件只計適用項目，不混用分母；隱藏或停用內容不刪除原有進度。
22. **數字明列意義。** 本站已收錄數、獎盃需求數與遊戲完整總數分開；未核實資料明示待查證，不當作零、已完整或實機驗收完成。

## 版面與功能取捨（23～28）

23. **功能與資料工具位置一致。** 桌面左側提供主要功能，右上放備份及適用的 Drive 工具；手機收合功能導覽。「備份與還原」採一致的按鈕入口與獨立視窗，各功能頁皆可直接開啟；匯出 JSON、匯入 JSON、完整備份集中在同一處，不以跳到來源頁或分散的下載按鈕代替。視窗支援關閉、Escape 與焦點返回；匯入差異確認沿用既有保護流程。沒有雲端需求的模組不為版面一致而增加雲端功能。
24. **地圖與攻略互相定位。** 有地圖的模組支援文字與點位互跳、標示目前目標；未查證位置不得製造精確座標，並保留來源及示意圖限制。
25. **控制管理功能數量。** 預設聚焦攻略、查漏與勾選，不主動增加筆記、個人標記、世界／成員等管理介面。已有實際用途的收藏與筆記保留，不因本規範全面移除；需要新增時依具體需求處理。

26. **抬頭收集摘要採完成度方塊。** 有明確分母的獎盃、收藏、圖鑑與技能等摘要，優先做成緊湊的完成度方塊，顯示類別、已完成／總數、百分比與實際比例計量條；整塊可直接進入對應查漏清單。數字與條長從同一份紀錄推導，不另存完成率，不將站內收藏達標代勾 PSN 獎盃。零進度的條長為零，分母未知時明示範圍，不製造精確百分比。窄螢幕可換行，維持易讀與可操作，不擠成微小數字。
27. **路線主功能下提供階段捷徑。** 左側「冒險路線」等主項目下面，直接列出章節／階段子項，點一下即可跳到該階段，並清楚標明目前位置；不要求先回首頁再找章節。子項可帶完成數，瀏覽與跳轉不代填進度、不鎖住未完成前置。手機收合在既有功能選單內，選定後收起；內容區可保留閱讀段落選擇，但避免重複堆放同一組大按鈕。

2026-11-23 使用者確認以上 26、27 項，先於 DQ3 模組套用；其他遊戲在相關介面修改時依此對齊，不因規範新增而批次改動。

28. **字級以早期模組的緊湊閱讀尺度為準。** 2026-11-27 使用者指出新兩款頁面字體偏大，確認早期模組大小較合適。新增遊戲應先比較 Talos II／Grounded 等既有頁面的實際字級與閱讀密度，不因是新模組而整頁放大。正文、步驟與清單名稱預設 **14px**，次要說明、來源、狀態與章節子項 **12～13px**；主功能與表格正文約 **14px**。頁標題約 **24px**（手機 **22px**）、區塊標題 **18px**、小標題 **16px**，完成度數字約 **20～22px**，依語意保持層級。
    - 取捨優先順序：長時間閱讀清楚、與既有遊戲一致、同畫面能對照足夠項目。用字重、留白與結構區分層級，不把一般正文預設成 16px、區塊標題放大到 22～24px，或為填滿寬螢幕而加大字體。長篇敘述確有需要時可局部用 15px，例外記於模組文件，不作整站基準；既有遊戲專用層級不因此全面改寫。
    - 字體縮小不等於縮小操作範圍：保留核取方塊與按鈕的易點尺寸，手機主要控制項維持至少 44px 高。重要警告不可縮成來源小字；圖解內的操作編號、原始畫面文字及放大檢視依辨識需求獨立處理。
    - 手機不將整頁字體放大；透過換行、欄位重排及行高約 1.6～1.65 保持可讀。保留瀏覽器縮放能力。驗收以新 browser context 在手機、平板、一般桌面及 1920／2560px 寬螢幕比對正文、標題、表格、導航與備份視窗，確認沒有截字、重疊或整頁水平溢出。

## 中文優先的具體用法（第 20 項補充 · 2026-11-27）

目的在降低外文辨識與自行翻譯的負擔，讓中文語系玩家直接看懂要去哪裡、找誰、拿什麼及如何操作。保留原文是為了對照遊戲或外文攻略，不讓原文成為主要閱讀門檻。

- **譯名優先順序：** 已核對的遊戲內繁中／官方在地化用詞 → 有來源且一致的社群繁中譯名 → 依原文語意整理的本站參考譯名。官方用詞須有適用平台／版本的證據；外文 Wiki 或中文攻略自行翻譯，不因此視為官方。尚未取得官方證據不阻擋參考翻譯先行使用。
- **主要名稱格式：** 優先使用「中文譯名（Original Name）」；清單較窄或名稱很長時，可將原文放下一行。中文維持正文尺度（約 14px），原文約 12～13px、正常字重，顏色需清楚可讀。不要把整列放大、把中文縮成附註，或預設英文在前中文在後。原文可自然換行，不截掉核對用的關鍵字。
- **攻略敘述：** 用自然中文寫清楚行進與操作；重要專有名詞在首次或有辨識需要時附原文，後續可只用同一中文譯名，避免一句話反覆堆疊完整雙語。角色、區域、清單、下拉選單、路線捷徑及同物品的各種出現位置使用同一份詞彙表。原生下拉無法分別縮小字級時，保留中文在前、原文在後即可。
- **參考翻譯標示：** 依範圍標明「社群譯名／本站參考譯名，未逐項核對遊戲官方中文」，可在清單說明與來源頁集中交代，不必每列重複同一警告。官方／社群／參考譯名混用時須能逐項追查類型與證據；真正有歧義或待確認的對應再逐項標示。譯名信心與物品取得位置、條件查證狀態分開，不能因翻成中文就提升攻略可信度。
- **缺少既定譯名：** 可採清楚的語意翻譯；角色等專名必要時採可辨識的音譯，保留原文。不要只把原文搬成另一種拼音而仍看不懂其用途，也不要為了中文補出原文未提供的效果、屬性或任務條件。少數確實無法判斷的詞可暫留原文並附中文用途／類別及待確認原因，列入補譯清單，不將整類資料留成英文。
- **搜尋及相容性：** 中譯、原文、已知別名與原有 ID 都能找到同一筆資料。保留原始名稱及原文來源，新增中文顯示欄位或詞彙對照；不得用翻譯後的顯示文字重建 ID、進度鍵或關聯，也不得為翻譯修改玩家保存的筆記與匯入原文。之後找到官方用詞時更新顯示並保留舊譯作搜尋別名。
- **驗收範圍：** 檢查主清單、標題、路線、地點、關聯連結及選單，而非只翻譯首頁；確認中文先出現、原文次要且可讀，中外文搜尋結果一致，手機／平板／寬螢幕不截字、不溢出，勾選、撤銷及舊進度仍可使用。

## 切換功能重設搜尋與篩選

- 切換主要功能時，清除搜尋並將篩選重設為目標功能的預設值；切回原功能也不恢復先前搜尋與篩選。此規則適用全部遊戲，包含 Grounded。
- 收集相關功能的預設狀態為尚未蒐集／未取得／未完成；其他功能依用途設定預設值，不把不同功能不適用的篩選互相套用。
- 目前功能內調整搜尋與篩選時依使用者選擇呈現，不因一般勾選或資料更新而重設。章節／區域分類切換不等同主要功能切換，依導航需求處理。
- 從獎盃缺項、配裝或地圖等具體連結前往目標時，可在預設值上套用該入口明示的定位或條件，確保目標可見；這不是恢復上次搜尋。
- 提供明確的清除搜尋／重設篩選入口。零結果時也能看出目前條件並清除，不因零結果自行重設。
- 搜尋與篩選是檢視條件，重設不影響完成進度、收藏或筆記，也不因此新增雲端同步；重設後閱讀位置應對應目前有效內容，不跳回已被篩除的舊位置。
