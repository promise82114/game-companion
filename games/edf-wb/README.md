# EDF WB 一代收集手帳

《地球防衛軍：世界兄弟》的武器、角色與配件收集手帳，依[攻略 Wiki](https://w.atwiki.jp/edfwb/)整理。保留日文原名、等級、分類與來源，提供繁中對照；部分名稱標示「參考翻譯」，供玩家核對。

開啟 `dist/index.html` 即可使用。若要本機 HTTP 預覽或離線快取，在專案根目錄執行：

```powershell
node server.mjs
```

開啟 http://127.0.0.1:4181/ 。免安裝套件、免編譯。預覽埠可由 `PORT` 環境變數調整。

## 清單與功能

| 類別 | 預設本篇 | 全部內容啟用 |
| --- | ---: | ---: |
| 武器 | 310 | 455 |
| 角色版本 | 186 | 209 |
| 配件 LV／型別組合 | 200 | 200 |
| 關卡 | 60 | 71 |

武器共 91 系列；角色為 62 名本篇角色各三版本、18 名 DLC／特典無印，以及五名 V01 別版本。額外內容預設停用，由「使用者設定」依實際導入內容勾選。DLC 及特典分頁與進度分母隨設定更新；取消只隱藏內容，保留既有取得進度。原特典與 V01 共用的 25 把武器不重複計數，任一導入來源啟用即可顯示。

- 日文／繁中／出處角色／關卡代號搜尋，分類、LV、版本及取得狀態篩選；預設「未取得」。
- 勾選立即存檔、復原、跨分頁同步、最近 12 份快照、JSON 備份合併與還原。
- 關卡提供武器 LV1–4／角色補收、重點查看、18 關推薦、我的最愛及每關筆記。
- 配件使用一代的攻擊／回復／移動／耐久分類，按 LV 與通常／新型／顏色型別記錄。只收錄 Wiki 表有數值的組合，空白列不推定存在；不套用二代品質詞綴或角色四欄裝備資格。
- 透過 HTTP 使用後保留離線快取。直接開啟 HTML 時不註冊 service worker。
- 保留二代既有 Google Drive 同步模組，專案識別與檔名獨立。此次未登入真實 Google 帳號、未驗證正式雲端同步；授權服務須允許目前網址來源。詳細格式見下方存檔說明。

## 日文資料與繁中維護

來源核對日期：2026-10-23。網站每列附一代 Wiki 連結，完整攻略與圖片請閱讀原站。清單完成率不是遊戲內任務達成度或獎盃分母。

`data/wiki-facts.json` 保存一代日文名稱、武器 LV、出處角色、配件型別與有數值的 LV、角色版本、關卡標題及分布名單。`sourceLine` 是此次讀取工具展開頁面的行號，供核對用，不是固定 Wiki 錨點。

`data/localization-reference.json` 保存從二代 commit `c49be804b91ce463bfb833b791edf468a80792dd` 取出的中文對照快照，共 526 個名稱／系列鍵值；含原始鍵值、完全相同／字形統一／明確別名等對應方式。`wb2Verified` 只表示二代既有核對紀錄，並不宣稱已核對一代遊戲畫面。`compositions` 記錄 36 個名稱／系列的詞段來源、來源中文、仍需翻譯的片段及組合方式；組合結果仍保留參考標示，產生器會核對詞段拼合與參考翻譯是否一致。`data/localization-fallback.json` 保存其餘 53 個名稱／系列的參考翻譯，不能覆蓋二代對照。

網站實際 455 項武器中 426 項沿用二代、29 項使用參考翻譯；209 項角色版本中 197 項沿用二代、12 項使用參考翻譯；配件組合中 140 項沿用二代本名，60 項本名為參考翻譯。配件型別中文另依一代原文翻譯。玩家頁面僅對缺漏對照的項目標示「參考翻譯」，其餘名稱不加來源標籤；不顯示跨代製作說明。合計 101 個收集項目、46 個不重複名稱（其中 86 項依詞段組合、15 項仍為獨立參考），詳細清單與計數方式見[參考翻譯待核對清單](docs/reference-translations.md)。

修改上述資料後執行：

```powershell
node scripts/build-data.mjs
node verify.mjs
```

產生的 `dist/data.js`、`details.js`、`translations.js`、`acquisition.js`、`content.js`、`mission-facts.js`、`recommendations.js` 與空的配件資格設定應一併保留。產生器不連外，也不需要二代 repo。穩定 ID 取自一代名稱＋LV／版本／型別，不依清單排序；中文修改不影響 ID。

## 存檔隔離與雲端

本機 key 為 `edfwb-progress-v1`、`edfwb-snapshots-v1`、`edfwb-backup-time`；JSON 的 `app` 是 `edfwb-collection`。雲端 envelope 的 `projectId` 與檔名分別為 `edfwb-checklist`、`edfwb-checklist.json`。一代不讀取二代 localStorage、備份或雲端檔案；匯入二代格式會拒絕。

共用 OAuth Client ID 是公開設定，並非憑證；Token 只在頁面記憶體。Google Cloud 的來源允許設定需另行確認，正式 GitHub Pages 與二代共用 `https://promise82114.github.io` 來源；本機測試需允許所用的埠。連接後的自動同步、版本衝突保護、取消勾選與筆記合併沿用二代模組，本次未操作真實 Drive 資料。

## 資料限制與驗證

角色關卡候選依一代[稼ぎ](https://w.atwiki.jp/edfwb/pages/198.html)的角色名稱名單推算全部版本，並非遊戲每場實際救出人數或掉落率。M25 前排除女僕姊妹；M38–59 列全角色候選，M60 無救出角色；M34 雖然僅一個救出名額，候選仍依該段名單整理。DLC／特典的早期詳細分布與逐版本差異未記載，不套用二代分布表。

追加任務的 55 把武器標為武器箱，出處角色僅作裝備加成參考；原站未提供逐型號關卡／難度表，故列在關卡頁的其他取得方式，不虛構特定 EX 掉落或二代的累計通關獎勵。`ヘブンズゲート・ランチャー` 在一代表列為 LV2，照原文保留。

`双葉理保(夏服)` 的獨立頁此次讀取失敗，以角色總表及武器頁確認並連回總表。五名別Ver的總表標示 V01，FAQ 使用 V1.01；本站以 V01 作版本識別並與原特典分列。完整核對記錄與未確認項目見 [資料來源與驗證](docs/data-review.md)。

`node verify.mjs` 使用 Node 內建 assert／vm，無第三方框架、不連外、不存取使用者進度，驗證 ID、中文來源、武器角色、DLC 連動、版本、配件空白列與跨遊戲備份隔離。桌面瀏覽器已實測搜尋、勾選、復原、重開、DLC、收藏筆記、關卡內補收、JSON 匯出、跨分頁同步與停止伺服器後離線重開；390px 手機版已檢查無水平溢出。真實 Google 授權／Drive、遊戲內繁中名稱與完整逐難度掉落表尚未核對。
