## UI 與持久化

主要工作問題：「現在去哪，離開前缺什麼？」採 Game Companion 左側功能、右上備份與既有尺寸帶，framed-sheet 輕量工具頁方向；盾劍符號、六珠條件與實際地名提供遊戲辨識。章節可自由跳，11 行進段落避免一口氣堆出全部長章；當前段落未完成全文顯示。完成後可回看，閱讀不寫完成進度。

收藏採清單而非大型橫表，全部符合條件的結果一次呈現；手機用分類下拉、緊湊列。攻略中的小型參考表隨頁面捲動，手機轉有欄名的堆疊列；唯一長資料框是匯入逐筆差異預覽。功能切換重設查詢，當前頁內更新保持查詢、焦點與閱讀位置。已取得目標的深連結可覆蓋預設條件，提供清除定位。

獨立 DB `game-companion.dragon-quest-iii-hd-2d-remake.progress.v1`。不讀 localStorage、其他遊戲、舊站 key 或真實 PSN／遊戲存檔。共用 store 不變，沒有建立中央 SDK。進度更新交易內重讀；精準撤銷比對每鍵修訂，阻擋同鍵後寫與 ABA，其他鍵可並行。

備份格式包含 format／gameId／platform／schemaVersion／dataVersion／exportedAt。原文在解析前封存；支援進度 envelope、同遊戲完整封存及匯入前復原包。未知 ID、欄位與兩端原文保留。來源缺項維持本機，較舊來源需額外核對；下載復原備份及確認後才放行。交易內以原文檢查過期，即使通知未抵達也不能覆蓋後寫。來源完整封存的歷史保存於本次封存原文，不跨資料庫寫入外部 record key。
