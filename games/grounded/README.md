# Grounded 庭院手帳

模組 1.14.1／schema 1，資料複查 2026-11-19。路線圖涵蓋 Grounded 本體。PS4／PS5 46 盃名稱採 BWIKI 用詞並保留英文，白金及部分收集項目使用本站繁中譯名。

從 repo 根執行：

```powershell
node games/grounded/verify.mjs
node scripts/build.mjs
node scripts/verify-site.mjs
node server.mjs
node scripts/verify-grounded-browser.mjs
node scripts/verify-grounded-ng-map-browser.mjs
node scripts/verify-grounded-smithing-browser.mjs
node scripts/verify-grounded-field-map-browser.mjs
```

入口 `/game-companion/games/grounded/`。需要 HTTP 及建置後共用資源，不使用 file URL。無產品套件、後端、OAuth 或 SW。站內座標與文字索引可在本機建置使用，庭院底圖隨網站提供，不再嵌入外站互動地圖，站內對應圖示保留 BWIKI 來源署名並由本站載入。Pages 沿用 main workflow。

## 功能與資料邊界

- 七階段、25 步遊玩路線圖。左側章節直達，各關鍵步驟並排顯示「先取得／準備」和「再前往」，窄螢幕依順序上下排列。依 `docs/PROGRESSIVE_ROADMAP_UX.md`，未完成時全文可讀；目標、相關獎盃及收集全部勾完才縮成摘要，可暫時回看。取消任一事項就恢復全文，重要警告持續可見。沒有目標模式／瀏覽章節選單、耗時或自訂備註。四大實驗室可依裝備平行探索。
- `dist/roadmap-progress.js` 從現有進度推導事項數量、全完成與下一步，不寫入新完成旗標。閱讀回看只存在頁面記憶體，重整後重新依完成度收斂；搜尋可暫時顯示已完成內容。章節完成數與「返回遊玩進度」亦使用相同判斷，不代填任何進度。更新時在原位修改 DOM，保留焦點及閱讀位置，不自動捲至下一步。
- 路線圖、收集清單與獎盃清單共用同一份紀錄，可直接勾選並篩出未取得項目。步驟、收集與 PSN 跳盃分別確認。
- 路線圖列出各區晶片交回後可購買的重點科技。開局的鍛造站在預設商店，霧靄超級晶片開放熔爐，黑蟻丘、沙盒、樹樁與奧美能磁碟接續不同階段的武防升級。
- 第一輪 100% 收集清單有 11 個分類、共 569 個核對列，預設一次顯示全部尚未取得項目，可按分類篩選，涵蓋 78 顆普通乳牙、45 顆巨型乳牙、51 個野外 SCA.B、108 個地標、68 張目標生物卡及 64 筆商店條目，也含庭院資料、晶片、防守、首領、腦力與結局。資料頁的潦草筆記列作 99% 查漏對照。切換到 NG+ 時，固定位置普通乳牙的勾選仍記在第一輪。遊戲報告卡為最終判準。
- 路線圖的 100% 查漏提供 13 條超級勝利條件，並能逐類展開本站已收錄項目。版本例外、多人補跳與實機達成尚待驗證。
- 武器頁收錄 88 筆武器、工具與箭矢，含持握方式、連段傷害、武器及傷害類型、元素、暈眩和水下可用性。防具的 22 套及 6 件探索散件分兩頁表格，依階級降序比較階級、減免、單件／套裝／光滑鍛造效果。兩頁可搜尋及篩選。
- 1.8.0 補武器「+6 鍛造與專屬效果」欄，可搜尋余震、流血、招架等效果；明列強悍分支限定、固有特效、消耗品不能鍛造及入注武器不繼承原型特效。舊腳蹼的 +6 新增效果仍未核實，感染螞蟻盾的爆炸抗性比例來源有差異，不顯示未確認數字。查證範圍見 [裝備補充](EQUIPMENT_RESEARCH.md)。
- 裝備列表整合武器與防具，上層分「武器列表／防具列表」，防具再分「套裝／散裝／盾牌」。盾牌收錄 5 面，預設只看第一輪 4 面；提供階級、格擋強度、觸發效果、取得階段與用途，明列盾牌不能鍛造及裝盾造成傷害降低 20%。切換分類重設搜尋與篩選，離開再回裝備時恢復原分類；既有武器、防具與盾牌連結仍可直達，頁內導航使用 `view=equipment`。
- 推薦配裝補入瓢蟲、西瓜蟲與火蟻三套的防禦、減傷、耐力、生存與輸出比較，第一輪及 NG+ 分開說明保留／換裝時機。NG+ 區分一般成長、灌注爆發與乳牙持續成長，不將一兩下倒地當作普遍必然，也不保證三階重甲能處理所有灌注效果。防具名稱可直達列表，內容全文常駐，不依進度隱藏。
- 推薦配裝新增 5 組環境裝備與 5 組工具強化建議，區分原有能力、光滑 +6、採集階級門檻、耐久與戰鬥收益。換裝會中斷三件套，但其餘單件效果保留；散件表增加實際單件防禦與抗傷，二階套裝頭／腿防禦依個別條目更正為 7.5。
- 異變頁整理 41 項 Grounded 本體異變的中英文名稱、效果及解鎖門檻，可按用途篩選。推薦配裝與推薦異變分頁。配裝按初、中、後期說明取得時機、升級順序、實戰使用及替換選擇，採常見近戰、瓢蟲吸血與火蟻輸出路線；推薦異變以使用場合為列，上方分為優先最多 3 項、候選最多 5 項（依條件替換，實際裝備上限仍為 5 項），直接列出名稱並按重要性排序，每項可附適用條件，依用途留白；一般戰鬥優先武器專精與有氧回耐，再以肺部增益補上限；穩定招架回耐的配法保留替換空間，採集／搬運不固定塞戰鬥異變，防護依敵人攻擊類型選用，名稱可跳到圖鑑。這些頁面可直接瀏覽，無需遊玩進度。
- 晶片解鎖頁列出 11 枚晶片的名稱、位置、前置及全部第一輪商店購買包，另列預設商店與奧美能磁碟解鎖。建築包形狀變體合併呈現，科技包補列實際配方，來源為 BWIKI 科學商店。

## 共用及保存契約

`shared/roadmap-store.js` 是從 Talos 抽出的單一交易實作，Talos 保留原 fresh／validate 預設；Grounded 以配置提供 fresh／validator。每次寫入在 IndexedDB 交易內讀最新值，BroadcastChannel 通知僅在本遊戲前綴。編輯會驗證世界／周目／成員未被另一分頁切換。建置發布 `_site/shared/`。

差異比較使用既有 Talos `sync-core.js` 的 merge／resolve，build 複製為 `_site/shared/merge-core.js`，不另寫同步或引入登入。Grounded 不啟用其 Journal／雲端流程。

DB `game-companion.grounded.progress.v1` 的 `records/progress` 保存 `gameId`、`schema`、`schemaVersion`、`revision`、`updatedAt`、`worlds` 與設定。世界內 `worldId`、成員 `playerId` 為穩定 UUID。快照 `snapshot.*`、匯入原文 `import.raw.*` 及通道均以 `game-companion.grounded.` 開頭，無 localStorage 或快取。

匯入順序：選檔 → 保存兩端原文 → 驗證遊戲及 schema → 逐筆差異選擇 → 下載復原包 → 使用者確認可讀已保存 → 同一交易比對預覽原文後寫入。上限 20 MB；解析錯誤、quota、下載失敗、預覽過期皆停止，不清空資料。

可匯入進度 JSON、完整備份中的 progress、兩端原文包中的 localRaw。完整備份的其他 archives 不盲目覆蓋當前 DB，而是連同來源檔原文保存在本次 archive；可再從完整備份取出。一般匯出包含未知進度欄位，完整匯出另含全部快照、兩端原文及損壞資料。瀏覽器只能發起下載，須實際開檔確認。

新增資料保留穩定語意 ID，不以排序／翻譯作索引。新 schema 不自動降級或歸零；目前沒有既有資料遷移。

## 1.1.2 白金流程驗收（歷史）
